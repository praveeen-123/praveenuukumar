FOOD DONATE - FLASK VERSION

1. Keep MySQL running in XAMPP. Your current MySQL port is 3307.
2. Open Command Prompt in this folder.
3. Run: py -m pip install -r requirements.txt
4. Run: py app.py
5. Open: http://127.0.0.1:5000

The Flask app automatically creates the demo database and required tables.
No Apache and no PHP are required.
If your MySQL password is not blank, set DB_PASSWORD before running.
